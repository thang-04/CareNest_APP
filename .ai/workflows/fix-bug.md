# Workflow sửa lỗi Mobile

1. Tái hiện lỗi với vai trò, màn hình, thiết bị/trạng thái kết nối liên quan và dữ liệu tối thiểu.
2. Lần theo navigation, state, API call và test; phân biệt lỗi client với response/contract BE.
3. Sửa hẹp, kiểm tra trạng thái tải/rỗng/lỗi, quyền và dữ liệu nhạy cảm liên quan.
4. Chạy test/build phù hợp với stack thực tế; báo rõ thiết bị, push hoặc API thật nào chưa được kiểm chứng.
